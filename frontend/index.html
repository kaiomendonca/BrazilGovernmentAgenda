Sobre a API

O BrazilGovernmentAgenda é uma API pública construída com FastAPI que coleta, normaliza e persiste os compromissos oficiais divulgados pelo Governo Federal, disponibilizando-os por meio de endpoints REST documentados.

Este site consome a API diretamente pelo navegador — sem intermediários — para exibir os dados em tempo real.

Endpoints principais

  • GET /eventslista de eventos com filtros e paginação
  • GET /events/{id}detalhe de um evento
  • GET /authoritiesautoridades monitoradas
  • GET /healthstatus da API

Dados públicos coletados via gov.br/planalto.

Projeto de portfólio — API própria em FastAPI + SQLAlchemy.
